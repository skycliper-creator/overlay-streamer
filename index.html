KODE BROWSER SOURCE OBS

Salin kode CSS kustom di bawah ini dan tempelkan ke kolom **Custom CSS** saat menambahkan Browser Source baru di aplikasi OBS Studio kamu untuk memproyeksikan glow neon asli:

/* Salin kode CSS berikut ke Custom CSS OBS: */
body {
    background-color: transparent !important;
    margin: 0px;
    padding: 0px;
    overflow: hidden;
}
.neon-border {
    border: 3px solid #ec4899;
    box-shadow: 0 0 10px rgba(0,0,0,0.8), 0 0 15px #ec4899;
    animation: border-pulse 4s infinite alternate;
}
@keyframes border-pulse {
    0% { border-color: #ec4899; box-shadow: 0 0 15px #ec4899; }
    100% { border-color: #06b6d4; box-shadow: 0 0 25px #06b6d4; }
}

💡 Langkah Memasukkan ke OBS Studio:

  1. Buka OBS Studio, tambahkan Source baru bertipe Browser.
  2. Isi lebar (Width): 1280 dan tinggi (Height): 720.
  3. Tempelkan tautan halaman web ini ke kolom URL (atau gunakan file lokal).
  4. Tempelkan kode Custom CSS di atas ke kolom input yang paling bawah. Selesai!
