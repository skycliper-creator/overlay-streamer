# 🚀 Twitch AI-Overlay Studio

Professional OBS Overlay Builder with AI capabilities.

## ✨ Fitur Utama
- **Customizable Themes:** Pilih berbagai tema seperti Cyberpunk, Retrowave, dll.
- **AI Integration:** 
  - *AI Background Generator* (via Imagen)
  - *AI Stream Booster* (Judul & Teks Marquee otomatis via Gemini)
  - *AI Co-Host Assistant*
- **OBS Ready:** Generator CSS otomatis untuk *Browser Source* di OBS Studio.

## 🛠️ Cara Penggunaan
1. Akses halaman aplikasi (atau jalankan `index.html` secara lokal).
2. Sesuaikan desain, warna, dan posisi elemen.
3. Klik "Dapatkan Kode OBS" untuk mendapatkan CSS custom.
4. Masukkan kode tersebut ke *Browser Source* di OBS Studio milikmu.
